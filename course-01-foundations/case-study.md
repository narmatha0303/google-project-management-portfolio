# Case study — Project management skills in a corporate retreat

**Course:** Foundations of Project Management, Module 2  
**Evidence:** Existing written reflection, graded 100%  
**Type:** Coursework scenario analysis  
**My contribution:** Written analysis of the project manager's actions. I did not deliver this retreat.

## Context

The course presented an event project with multiple tasks, spending controls, client changes, and time-sensitive decisions. My responses examined how a project manager kept the work coordinated.

## Analysis based on my submission

| Skill | Action identified in my response | Why it matters |
| --- | --- | --- |
| Decision-making | Defined spending limits and approval requirements; arranged client decisions before a deadline | Gives the team decision authority while retaining control over larger commitments |
| Communication | Used status emails and direct client conversations | Keeps stakeholders aligned and surfaces decisions that need attention |
| Flexibility | Coordinated a requested theme change across creative work | Helps the team respond to changed expectations |
| Organization | Used a spreadsheet to track tasks and responsibilities | Makes ownership and work progress visible |

## Evidence and limits

[Read the reviewed responses](assignments.md). Coursera recorded 100% for the reflection. That grade supports completion of the learning activity; it does not demonstrate a real event outcome or prove professional delivery experience.

## Interview discussion

Explain how these actions relate to a project you have personally worked on. Describe your own responsibilities, an actual decision, and evidence of the result. Keep the coursework example clearly identified as a simulation.
